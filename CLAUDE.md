# Instructions permanentes pour ce dépôt

## Numéro de version des applis
- bureau-app/index.html et client-app/index.html affichent chacun un numéro de version dans leur en-tête (ex. 'V1.00').
- À CHAQUE modification apportée à l'un de ces deux fichiers (quel que soit le prompt reçu), incrémente automatiquement son numéro de version de 0.01 (V1.00 → V1.01 → V1.02, etc.), même si la demande ne le mentionne pas explicitement.
- Mentionne toujours le nouveau numéro de version dans ton résumé de fin de tâche (ex. 'bureau-app passe en V1.03').
- Si les deux fichiers sont modifiés dans le même prompt, incrémente les deux indépendamment.
